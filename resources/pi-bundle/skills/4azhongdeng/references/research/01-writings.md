# 李三水（W）/ 杨烨炘（天与空）著作与系统长文调研

## 李三水（W创始人）

### 书籍
- 未发现李三水出版过系统性著作。其思想主要通过行业媒体专访、演讲和公司发布内容传播。

### 核心概念与自创术语
1. **"不做创意人，只做创造者"** - W的核心价值观，区分"创意"（surprise）和"创造"（method to create surprise）
2. **"野狗文化"** - 公司文化定位：耐饿、固执、不灵活、爱作品胜过爱公司
3. **"创意不值钱"** - 创意人人都有，真正值钱的是创造性的思维和方法
4. **"创造起跑线，不做巅峰"** - W的定位是创造行业新标准/新起点，而非争第一
5. **"横空出世的0"** - 想要创造规则，做那个"0"（起点）而非注定衰落的"No.1"
6. **"野狗科艺舱"** - W内部的技术/艺术/音乐创新单元

### 核心论点（高频≥3次）
1. **策略与创意一体论**："最好的策略就是最好的创意，最好的创意就是最好的文案"（在多篇采访中重复）
2. **危机意识**："盛极必衰，大热必死" - 带着危机感看成功
3. **悲观主义驱动**："因为悲观反而带来更多的决绝"
4. **行业批判**：认为行业不缺创意人，缺的是企业家精神
5. **"没有企业的时代，只有时代的企业"** - 成功是顺势而为
6. **创造vs创意**：创意是惊喜（人人能有），创造是找到制造惊喜的方法（升维竞争力）

## 杨烨炘（天与空创始人）

### 书籍
- 未发现杨烨炘出版过系统性著作。

### 核心概念与自创术语
1. **"人文主义广告"** - 广告应关注人本身，而非只是商品
2. **"社会创意"** - 创意应具有社会价值和公共意义
3. **"事件营销作为牵引"** - 以事件营销为核心，聚合物料、聚焦传播
4. **"把天与空当作品牌来做"** - 公司自身品牌建设
5. **"品牌主需要一点点冒险精神"** - 对客户的呼吁

### 核心论点（高频≥3次）
1. **事件营销牵引论**：天与空的所有营销活动都以事件营销作为核心牵引力
2. **4A升级论**：不是"去4A"，而是"升级4A"，结合传统创意能力和数字传播
3. **创意勇气论**：中国广告人太胆小，不敢做真正的创意
4. **社会价值论**：创意应具有社会价值，而非纯商业
