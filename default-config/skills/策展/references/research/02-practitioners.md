# 策展文化融合 · 实践者对话调研

> 调研日期：2026-07-20

---

## 一、原研哉的实践方法

- **跨领域召集**：每次展览邀请不同领域创作者（建筑师/服装设计师/平面设计师/产品设计师/摄影师/工业技术企业）
- **约束性Brief**：极度聚焦但概念性的命题——"只从触觉出发设计""重新设计日常用品"
- **展览即研究**：展览本身是研究方法而非成果展示
- **每次展览测试一个哲学命题**：如果只从触觉出发设计会怎样？如果强行重新设计已不可见的日常之物会怎样？

**经典引语**：
> "设计始于对未知的理解。"
> "Ex-formation让人意识到自己知道得有多么少——从而看到更多。"

## 二、Hans Ulrich Obrist的实践方法

- **对话驱动**：通过持续采访艺术家生成展览概念
- **反体制**：回避白立方美术馆的权威性，厨房展→街头展
- **参与式**：观众不是消费者而是共同创造者
- **来源**：一手（本人著作+访谈）

## 三、中国策展人的实践话语

### 金冈（乡村策展人）
- **角色定位**：策展人是"文化翻译"而非"代言人"——让乡村艺术成为言说主体
- **操作**：在地性策展作为微观更新策略，通过艺术干预振兴特定场域
- **可信度**：二手（学术会议报道）

### 王晓松
- **核心主张**：展览作为方法——不是静态结果，而是通过信息转换与衍生进行知识生产

### 高远
- **观察**：中国当代艺术呈现空间化/装置化/场域意义叠加/独立替代空间兴起/跨媒体与虚拟转向

## 四、实践共识模式

| 模式 | 操作 |
|------|------|
| 跨领域协作 | 不同专业背景参与创作 |
| 约束即创意 | 限定但概念性的brief |
| 展览即提问 | 展览让人带着问题离开 |
| 从具体到普遍 | 本地文化起点→普遍可及体验 |
| 文化翻译而非文化输出 | 创造环境让观众自己感受 |
