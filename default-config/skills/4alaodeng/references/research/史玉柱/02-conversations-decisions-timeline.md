- **节目名称**：《跌倒的巨人能否站起》（1997年后）、《一个著名的失败者》
- **来源**：CCTV纪录片素材汇编 **[一手]**

### 1.2 对失败（巨人集团破产）的反思

史玉柱在不同场合反复反思巨人失败，核心要点提炼如下：

#### 四大失误（史玉柱自述，综合多场访谈）**[一手/二手-直接引用]**

| 失误 | 具体内容 |
|------|---------|
| 1. 盲目追求发展速度 | 1995年目标10亿→1996年50亿→1997年100亿，未经科学论证 |
| 2. 盲目多元化经营 | 涉足电脑、房地产、保健品等十几个行业，跨度太大 |
| 3. 决策机制缺失 | 个人股份占90%以上，董事会形同虚设，无人能干预错误决策 |
| 4. 忽视技术创新 | 电脑业走入低谷后忽视技术创新，二次创业失利与此有关 |

#### 民营企业的13种"死法"（史玉柱总结）**[二手-转述/分析]**

## 二、决策与行动

### 2.1 从巨人集团破产到脑白金东山再起（1997-2001年）

#### 关键决策链

**① 失败的应对（1997年）**
- 事件：巨人大厦资金链断裂，欠债2.5亿元，媒体"地毯式"报道
- 决策：尝试挽救——5个月跑遍国内外找投资者，全部失败
- 反思：史玉柱后来承认——"当时如果朋友注入钱，自身没有深刻反思的话，也只会是糟蹋朋友的钱" **[二手-直接引用]**
- 行动：爬珠穆朗玛峰，差点丧命——"爬上去是享受，死了比自杀光彩" **[二手-直接引用]**

**② 二次创业的决策逻辑（1998年）**
- 启动资金：向朋友借了50万元
- 选品逻辑：在珠海巨人时期就有保健品战略储备——"找了专家研究下个世纪什么最有发展前途，结论是生命科技" **[二手-直接引用]**
- 试水策略：**只做一个县**——选择江苏江阴作为起点
  > "在江阴走家串户地调研，老头老太一看到我去就搬个板凳坐在院子里跟我聊。" **[二手-转述/分析]**
- 铁律制定：
  1. 时刻保持危机意识
  2. 不得盲目冒进、多元化
  3. 永远保持充沛现金流

**③ 脑白金营销组合拳（1998-2000年）**
- 产品端：口服液+胶囊的独特剂型，强调"快速见效"
- 定位端：从"保健品"转为"礼品"——"今年过节不收礼，收礼还收脑白金"
- 调研端：要求团队每月至少跟100个消费者深度交谈
- 广告端：
  - 报纸软文（伪装成新闻报道，如"脑白金席卷全球"）
  - 电视广告卡通老人系列，连续投放10年不变
  - **"脉冲式投放"**：春节前20天+中秋前10天集中轰炸，其他时间大幅减少
  - 广告语长期被评"十差广告"之首，但产品连续畅销
- 渠道端：**农村包围城市**——从江阴→无锡→南京→常熟→吉林→全国
  > "做全国性市场，一定要先做一个试销市场，要一点点来，快不得；做成了，真到做全国市场时，要快半步，慢不得！" **[二手-直接引用]**

**④ 还款决策（2001年）**
- 决策：高调还清2.5亿个人债务
- 动机：史玉柱自述——"因为我曾经不诚信过，我发现这个成本太高了。三年之期到了我没还出来，老百姓看到我的愤怒眼光，那种打击非常大的。" **[二手-直接引用]**
- 市场效果：形成巨大公关事件，脑白金品牌信誉飙升

### 2.2 征途游戏的营销策略（2004-2007年）

#### 进入网游的决策逻辑
- 时机：2003年将脑白金等保健品业务出售（套现），转身进入游戏行业
- 原因：自述"保健品空间不大"，且本人是"骨灰级玩家"
- 验证方法：亲自做玩家，一天泡15小时，充当GM（客服）了解玩家需求
- 史玉柱自述："我有'三年不开手机'的专注经历"（指全身心投入《征途》早期研发）

#### 营销策略
| 策略 | 具体做法 | 来源可信度 |
|------|---------|-----------|
| **免费模式** | 率先在国内实施"免费游玩+道具收费"，颠覆当时计时收费模式 | **[二手-直接引用]** |
| **目标人群** | 聚焦刚进入社会的成年人，而非在校学生 | **[二手-转述/分析]** |
| **人性化设计** | 让有钱人为荣耀付费、让男玩家为女玩家付费、让玩家有"国王"感 | **[二手-转述/分析]** |
| **地推** | 复制脑白金的地面推广团队，深入二三线城市网吧 | **[二手-转述/分析]** |
| **口碑传播** | 网游营销靠口碑，而非传统广告 | **[二手-直接引用]** |

#### 应对道德争议
- 争议焦点：游戏是否"毒害青少年"、是否将"金钱"价值观引入游戏
- 史玉柱回应：
  > "公司运营的游戏在注册时以身份证号码进行年龄限制，注册后发现有未满18岁的证据立即踢下线，是国内第一家。" **[二手-直接引用]**
  > "任何游戏公司都要面临这个追问。" **[二手-直接引用]**
  > "要看你把网游看成什么行业，如果是教育行业就有问题，如果是娱乐行业就没有问题。" **[二手-直接引用]**

### 2.3 巨人网络上市（2007年）

**关键决策：**
- 公司名称：坚持将"征途公司"更名为"巨人网络"，股票代码选择GA（Giant）而非ZT

## 四、史玉柱式营销方法论提炼

### 4.1 "农村包围城市"策略

**操作范式：**
1. **选点**：选择一个县级市场（江阴）作为试点
2. **调研**：走家串户，与目标消费者面对面，收集一手信息
3. **验证**：在样本市场跑通营销模型
4. **复制**：从县级→地级市→省级→全国
5. **节奏**："样本市场快不得，全国市场慢不得"

### 4.2 核心营销原则

| 原则 | 含义 |
|------|------|
| **消费者是唯一专家** | 花70%精力研究消费者，20%做终端执行，10%管经销商 |
| **集中优势兵力** | 一个时期只做一件事，集中资源打歼灭战 |
| **第一法则** | 挖掘产品/品牌的"第一"属性，猛攻这一点 |
| **脉冲式投放** | 旺季集中轰炸，淡季大幅减少或停投 |
| **知名度＞美誉度** | 先让消费者记住，再考虑喜好 |
| **广告是投资不是费用** | 广告要持续投放，最怕变 |
| **事件营销** | 制造新闻点让媒体主动报道，降低传播成本 |

### 4.3 与其他营销人的差异

| 维度 | 史玉柱 | 其他典型营销人 |
|------|--------|---------------|
| **理论来源** | 毛泽东思想（十大军事原则、集中优势兵力） | 西方营销理论（定位、4P等） |
| **对理论的态度** | "大学营销教材80%是错的" | 依赖经典理论框架 |
| **调研方法** | 老板亲自下市场，走家串户，与消费者面对面 | 委托第三方/数据分析 |
| **广告风格** | 俗、重复、功能直接、不讲故事 | 追求创意、品牌调性、内容营销 |
| **渠道策略** | 农村包围城市，先易后难 | 一线城市切入，辐射全国 |
| **风险控制** | 账上长期放巨额现金，不负债 | 加杠杆扩张 |
| **产品选择** | 必须是见效快的产品（消费者能立刻感受到效果） | 注重品牌溢价、长期心智 |
