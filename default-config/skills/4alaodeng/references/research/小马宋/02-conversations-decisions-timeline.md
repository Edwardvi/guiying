### 2. 被追问时的回答方式

- **不回避失败**：坦然承认"离开奥美是错误决策"，承认前两次创业"没做出多大规模"。
- **对比稿的态度**："不比稿"是原则，但坦承"当客户不找我的时候，我就该去比稿"。
- **被问"为何不自己做品牌"**：回答"我没有管理复杂业务的能力，所以只能做咨询这种简单的业务模式"。
- **被质疑"方法论"**：强调"所有模型都是错的，只在特定尺度上成立"（引用统计学家乔治·博克斯）。
- **关于自身实力**：多次说"运气成分很大"，"我本不是学霸，班上最聪明的脑子能秒我"。

## 二、决策与行动

### 1. 从奥美到创业的历程

**关键决策链**：

```
锅炉工（中石化） → 经济观察报策划 → FCB文案 → 奥美互动 → 蓝标策略总监
→ 乐问网创业（失败）→ 第九课堂创业（失败/退出）→ 暴风影音市场负责人
→ 几件事公司（2016）→ 小马宋战略营销咨询（2019转型）
```

- **2008年加入奥美**：实现了"进最牛广告公司"的梦想。但2009年因不喜欢新领导离职。—— **自评："错误决策"，是"福兮祸之所依"**。
- **2011年第一次创业（乐问网）**：模仿美国formspring做问答社区，融了资但模式在中国行不通（隐私/敏感话题问题），两年后关站。
- **2011年第二次创业（第九课堂）**：模仿美国skillshare做技能分享平台。通过这个项目学会经营小公司、积累自媒体基础、认识早期团队。2013年因不想做培训公司而退出。
- **2014-2015年暴风影音时期**：担任市场负责人，拿到价值2000万+的期权（暴风上市40天36个涨停板）。同时运营公众号积累8.9万粉丝，业余接私活收入超主业。期间参与策划罗辑思维"甲方闭嘴"、"papi酱广告拍卖"、"时间的朋友"跨年演讲。
- **2016年2月29日第三次创业**：成立"几件事"公司，定位做网络事件营销。"低风险创业"——有暴风2000万股票打底、有公众号粉丝、有两个确定客户（罗辑思维和京东）。

**核心方法论**：
1. 不靠"一招鲜"——每个客户有独特解法
2. 营销不仅是传播，更要从企业经营层面思考
3. 通过"价值罗盘"（功能性价值→体验性价值→象征性价值）系统评估
4. "创意是关键性因素，执行是决定性因素"

### 4. 对营销行业的判断

| 判断 | 详细内容 |
|------|----------|
| **营销的边界** | "营销只是企业经营的一部分，顶多占25%的重要性"——业务模型有问题，营销再成功也没用 |
| **4P是永恒框架** | "营销永远跑不出4P的框架" |
| **行业去中介化** | 甲方市场是乙方的100倍，建议新人去甲方发展 |
| **细分趋势** | "商业的趋势是越来越细分"——建议掌握细分技能（美团打榜、抖音本地生活、小红书笔记） |
| **AI重塑行业** | 替代基础工作，但无法替代专业创意判断 |
| **渠道为王** | "渠道越来越重要"、"99.9%的产品都可以代工，核心是怎么卖出去" |

1. **广告人 → 甲方案例**：在暴风影音理解了"企业经营"的全貌，不再只盯着传播。
2. **两次创业失败的价值**：乐问网和第九课堂的失败让"学会了如何经营一家小公司"。

5. **"不比稿"的底气来自口碑**：通过公开内容（公众号、播客、演讲）持续建立专业信任。

### 客户服务方法论

| 维度 | 方法 |
|------|------|
| **准入** | 提前确认工作方法/理念/准则一致，不接"底子不好"的企业 |
| **诊断** | 从经营视角出发，找到本质问题，而非直接给传播方案 |
| **解法** | 因客户而异——"所有模型都是错的，只在特定尺度上成立" |
| **执行** | "创意是关键因素，执行是决定性因素"——跟进落地 |
| **考核** | 以客户生意增长为终极指标，而非传播曝光的KPI |
