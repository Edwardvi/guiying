# 中国广告营销 · 实战方法论框架

> 基于叶茂中、小马宋、史玉柱三位顶级营销人的思维提炼

本框架将三位中国最具代表性的营销人的实战方法论进行系统化提炼，形成一套**可操作的营销决策参考系统**。

## 一、领域共识心智模型（四人合）

以下4个心智模型是三位营销人都认同的核心原则，是中国广告营销领域的"公理"。

### 模型1：人性洞察为本

**一句话**：营销的根基在对人性的理解，不在理论或创意。

**三方证据**：
- 叶茂中：冲突源于人性的复杂——"需要vs想要""理性vs感性"
- 小马宋："营销本质是满足顾客价值"，亲自到店面观察顾客行为
- 史玉柱："营销没有专家，唯一的专家是消费者"，强制全员每周访谈50个消费者

**应用**：遇到任何营销问题，第一步不是想方案，而是回到消费者——他们是谁、在哪、想要什么、怕什么。

**局限**：洞察人性是慢功夫，不能快速出方案；不同人群的人性表现差异巨大，容易用自己熟悉的群体代替目标群体。

### 模型2：效果压倒艺术

**一句话**：营销的最终目的是卖货，不是获奖、不是自嗨、不是艺术表达。

**三方证据**：
- 叶茂中："拿人钱财，替人消灾"，广告不为讨好观众，为让观众行动
- 小马宋："营销核心是创造价值并获得回报"，所有动作最终指向经营结果
- 史玉柱："能变成销量的营销才是好营销"

**应用**：评估营销方案时，第一个问题永远是"这能让更多人买吗"。判断一个广告好不好，看销量不看口碑。

**局限**：极端效果导向会导致短期行为，牺牲品牌长期资产。小马宋对此最谨慎。

### 模型3：传播需要饱和攻击

**一句话**：营销传播不是涓涓细流，是洪水——要么够猛，要么别打。

**三方证据**：
- 叶茂中："一力降十会"，集中资源打透一个点
- 小马宋：承认"过去央视打广告是最有效的方式，因为能集中触达"
- 史玉柱：聚焦策略——"集中优势兵力，各个歼灭敌人"

**应用**：预算有限时，宁可在单一渠道打到饱和，也不要分散到多平台蜻蜓点水。

**局限**：饱和攻击的前提是选对了渠道和打法，否则是烧钱。信息碎片化时代，单一渠道饱和的成本极高。

### 模型4：广告是长期投资

**一句话**：广告不是花销，是对消费者大脑的投资，需要持续重复才能积累。

**三方证据**：
- 叶茂中："重复带来刺激，不断重复可以形成条件反射"
- 小马宋：品牌需要长期建设，"广告的作用之一是提醒和强化记忆"
- 史玉柱："广告语能不变尽量不要变"，脑白金广告语打了20年

**应用**：确定一条好的广告语后，坚持打、不要频繁更换。换广告语等于之前的投资打水漂。

**局限**：广告环境变化快（平台算法、用户习惯），固守不变可能被淘汰。需要在坚持核心信息的同时更新表现形式。

## 二、三套流派体系

### 流派A：叶茂中 — 冲突理论

#### 核心逻辑

```
发现冲突 → 制造冲突 → 解决冲突 → 引爆传播
```

#### 理论内核

- **需求来自冲突**：人的需求有限，欲望无限；理性左脑vs感性右脑的冲突是营销的起点
- **三流营销**：寻找冲突（发现市场中已有的矛盾）
- **二流营销**：解决冲突（提供方案满足需求）
- **一流营销**：制造冲突（创造新的矛盾点燃市场）

#### 核心打法

| 战术 | 说明 | 案例 |
|------|------|------|
| **简单粗暴重复** | 广告语要短、要洗脑、要重复到形成条件反射 | "赶集网，啥都有" |
| **央视+明星** | 用最高势能的媒体+最有辨识度的面孔 | 真功夫（李小龙形象） |
| **制造话题争议** | 广告本身就是新闻，让媒体免费报道 | 知乎"发现更大的世界"世界杯广告 |
| **进攻左脑或右脑** | 要么讲道理（理性说服），要么讲感情（感性冲击） | 马蜂窝（旅游攻略，理性）vs 海澜之家（一年逛两次，感性） |

#### 适用场景

- 品牌从0到1，需要快速打开知名度
- 行业竞争激烈，需要差异化破局
- 目标人群广泛的大众消费品

#### 局限

- 互联网时代效果递减（央视垄断不再、用户有屏蔽广告的能力）
- 能解决"让人记住"的问题，不能解决"让人喜欢"的问题
- 引发争议可能损害品牌长期形象
- 制造冲突≠编造概念，后者触及道德底线（叶本人曾公开道歉）

### 流派B：小马宋 — 4P实践派

#### 核心逻辑

```
营销的营，首先是经营的营
4P（产品、价格、渠道、推广）是永远的框架
```

#### 理论内核

- **营销是经营的一部分**，不是独立职能。企业成功本质是经营逻辑的成功，不是靠一个营销点子
- **4P框架不过时**：产品（Product）、价格（Price）、渠道（Place）、推广（Promotion）是完整系统
- **创造价值 → 传播价值 → 传递价值**：三个环节缺一不可
- **反对定位教条化**："所有模型都是错的，只在特定尺度上成立"

#### 核心打法

| 战术 | 说明 | 案例 |
|------|------|------|
| **产品是营销的基石** | 在产品上做文章本身就是最好的营销 | 元气森林"0糖0脂0卡"（产品创新即营销） |
| **渠道决定生死** | 创业公司渠道能力比营销能力更重要 | 古茗奶茶（深耕三四线渠道） |
| **推广三目标** | 让顾客产生记忆、购买、传播 | 得到的"知识就在得到" |
| **POM模型** | 消费者决策受个人偏好(P)、品牌传播(O)、第三方影响(M)共同作用 | 熊猫不走蛋糕（第三方口碑驱动） |

#### 适用场景

- 品牌发展期，需要系统化建设
- 产品已具备竞争力，需要优化渠道和推广
- 新消费品牌、互联网品牌

#### 局限

- 没有标志性的"爆款理论"，品牌辨识度不足
- 对初创期"从0到1"的爆发力不如叶茂中式打法
- 系统方法论需要时间落地，不适合需要速效的场景

### 流派C：史玉柱 — 消费者导向实践派

#### 核心逻辑

```
把目标消费群研究透了，路子就对了
广告是对消费者大脑的投资
```

#### 理论内核

- **消费者是唯一专家**：所有决策从消费者出发，不是从理论出发
- **广告是投资不是花费**：好的广告语是资产，要持续积累不更换
- **试销→修正→推广**：小范围验证有效再大规模投入
- **聚焦集中兵力**：不分散资源，攻一个点打透

#### 核心打法

| 战术 | 说明 | 案例 |
|------|------|------|
| **礼品定位** | 不谈产品功能，谈社交价值 | "今年过节不收礼，收礼只收脑白金" |
| **软文打基础+硬广做维护** | 先用公关软文建立认知，再用广告维持重复 | 脑白金软文系列（"人类可以长生不老？"） |
| **脉冲式广告排期** | 集中投放+间歇休整，非全年均匀投放 | 脑白金仅在春节/中秋前集中轰炸 |
| **农村包围城市** | 从下线城市切入，避开一线红海 | 脑白金从县城做到省会再到全国 |
| **一把手抓营销** | CEO亲自盯广告细节，不外包 | 史玉柱亲自写广告语、审软文 |

#### 适用场景

- 下沉市场、大众消费品
- 预算有限需要精打细算
- 需要从实践中总结打法，而非套用理论

#### 局限

- 方法论高度依赖特定时代（信息不对称、央视垄断），互联网时代需改造
- "恶俗但有效"的理念可能导致品牌形象低端
- 产品本身如果不过关，营销越猛死得越快

## 三、决策启发式

### 通用启发式（三人共识）

1. **先研究消费者，再想创意**
   - 场景：任何营销项目启动前
   - 操作：花70%时间研究目标人群，30%时间想方案
   - 来源：三人均强调消费者调研第一

2. **广告语定了就不要变**
   - 场景：确定核心传播信息后
   - 操作：一条好的广告语至少要打3-5年，不要每年换
   - 来源：叶茂中"重复"、史玉柱"不变"、小马宋"品牌需要长期建设"

3. **预算有限时聚焦单一渠道**
   - 场景：总预算<500万时
   - 操作：选一个渠道打到饱和，不要分散
   - 来源：三人均推崇"集中兵力"原则

4. **好产品是营销最大的杠杆**
   - 场景：产品还未打磨好时
   - 操作：先优化产品再投入营销，否则营销加速死亡
   - 来源：小马宋核心主张，叶茂中和史玉柱也在不同场合承认

### 流派差异启发式

| 场景 | 叶茂中式选择 | 小马宋式选择 | 史玉柱式选择 |
|------|------------|------------|------------|
| 预算极少时 | 制造一个话题/争议，让媒体免费报道 | 优化产品，让产品本身成为传播源 | 找一个小市场试销，验证模式 |
| 对手很强时 | 制造冲突：树敌、挑战老大 | 差异化定位，找对手覆盖不到的价值点 | 农村包围城市，不打正面战 |
| 需要快速起量 | 洗脑式重复+明星背书 | 渠道铺设+口碑裂变 | 软文铺垫+硬广饱和攻击 |
| 品牌老化时 | 换代言人、换广告语、搞大事件 | 产品创新+渠道更新 | 要么不做，要做就全力投入 |
| 线上vs线下 | 线上制造话题，线下用硬广 | 全渠道系统运营 | 重线下，线上只是补充 |

## 六、核心张力

### 张力1：效果导向 vs 道德底线

- 叶茂中和史玉柱的实践中存在夸大宣传、编概念的问题
- 小马宋强调"不欺骗消费者"
- **处理**：使用此框架时，效果导向需以合法合规为前提。"编概念"和"制造冲突"之间有一条线，不可逾越

### 张力2：土但有效 vs 审美升级

- 简单粗暴的广告有效，但会拉低品牌形象
- 精致的广告好看，但可能记不住
- **处理**：根据品牌阶段做取舍——初创期偏"有效"，成熟期偏"有品"

### 张力3：个人经验 vs 可复制方法论

- 三人的成功很大程度上依赖个人能力（叶的创意、马的理性、史的实战）
- 方法论可以被学习，但直觉和判断力来自长期积累
- **处理**：框架提供方向，具体执行需要结合自己的行业认知

## 七、诚实边界

此框架基于公开信息提炼，存在以下局限：

- **时代局限性**：叶茂中和史玉柱的方法论形成于电视/央视时代，在互联网/算法时代需要改造，不能照搬
- **个人依赖性**：三人的成功很大程度上依赖个人特质，框架不能复制他们的直觉和判断力
- **案例选择性偏差**：公开案例多为成功案例，失败案例（尤其叶茂中操盘后失败的品牌）记录不足
- **信息截止时间**：调研截止2026年7月，之后的新动态未覆盖
- **未被覆盖的流派**：中国广告营销还有华与华（超级符号）、君智（定位咨询）、4A体系等未纳入此框架
- **三人均不是纯粹的理论家**：他们的方法论偏实战总结，学术严谨性不如科特勒等西方理论家
